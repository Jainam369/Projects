Interacting DM-DE : In this file there are two separate files of dark sector interaction. The ipynb file is just the numerical analysis of the model presented in the paper https://arxiv.org/abs/2604.08449v2.
While the other files are related to different model and a parameters estimation has been done for the model. Here, I have taken an inspiration
of the structure of the code from https://github.com/sleonardokap/cosmological_data.



LCDM : Here I estimated the parameters Omega_m and Hubble parameter for Lambda CDM model with using Baryon Acoustic Oscillation of SDSS and DESI, Cosmic Chronometer(CC) and Type-IA supernovae data from Dark Energy Survey(DES).


Supernovae: Here, for light curve analysis I have taken DES 3YR datasets in the BRICS capstone project. In another ipynb file I have taken DES-Dovekie updated datasets to constraint Omega_m and equation of state parameters for wCDM model. The results of the parameters are fall within 1 sigma error of their reported values in the actual paper,https://arxiv.org/abs/2511.07517v3 in Table 10.
